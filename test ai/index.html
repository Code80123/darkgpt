Fonctionnalités

Conçu pour les développeurs

Un client de chat complet et autonome, prêt à connecter à n'importe quelle API compatible OpenAI.

Code sans filtre

Génère du code complet et fonctionnel, sans squelette vide ni commentaires inutiles. Langages et frameworks variés.

Streaming fluide

Réponses en temps réel, markdown rendu à la volée, coloration syntaxique, bouton copier sur chaque bloc de code.

Multi-modèles

Compatible avec toutes les API OpenAI-like : LM Studio, Ollama, vLLM, OpenAI, Groq, OpenRouter…

100% local

Tes conversations restent dans ton navigateur (localStorage). Aucune donnée envoyée à un tiers, sauf à ton propre serveur.

Édition & régénération

Modifie un message et relance, régénère une réponse, copie ou supprime n'importe quel message d'un clic.

Gestion du contexte

Élagage automatique des vieux messages pour ne jamais dépasser la fenêtre de tokens du modèle.
